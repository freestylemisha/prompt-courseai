How to play

Every day there is one new color, the same for everyone. Guess its six-digit hex code in six tries.

A hex code is three pairs: RR red, GG green, BB blue. Digits run 0–9 then A–F (A=10, F=15). Bigger means more of that light: #FF0000 is pure red, #000000 is black, #FFFFFF is white. The strip on each key shows how bright that digit is.

7

Exact digit.

C▼

One or two away. The arrow says go lower.

3▲

Three or more away. The arrow says go higher.

Each guess shows your color beside it with a match score. The small range under each empty tile shows which digits are still possible.

Tip: start by judging each channel. A bright, warm color has a high first pair. A dark color has low digits everywhere.

Keyboard works too: type 0–9 and A–F, Backspace to delete, Enter to guess.
